# אולפן התמונות · Image Studio

מערכת פנימית לחיתוך, מיקום ועיצוב של תמונות לפני העלאתן לאתר.
נבנתה ללא שום תלות חיצונית (Node בלבד, בלי npm install), עם ממשק בעברית מימין לשמאל,
סליידרים לכל פעולה, גרירה חופשית בעכבר ותמיכה מלאה במקלדת.

An internal image cropping studio: zero runtime dependencies, RTL Hebrew UI,
sliders for every transform, free mouse dragging and full keyboard support.

---

## הפעלה מהירה

```bash
npm start
# פתחו http://localhost:3000
```

הפעלה עם שינוי אוטומטי בזמן פיתוח:

```bash
npm run dev
```

הרצת הבדיקות:

```bash
npm test
```

אין צורך ב-`npm install` — למערכת אין תלויות. נדרש Node 18.17 ומעלה.

## מה אפשר לעשות

- **העלאה נוחה** — גרירת קבצים לכל מקום בעמוד, בחירה מהמחשב, או הדבקה מהלוח עם `Ctrl+V`.
  אפשר לטעון כמה תמונות יחד ולעבור ביניהן; כל תמונה שומרת את ההגדרות שלה.
- **הזזה עם העכבר** — גרירה מזיזה את התמונה בתוך מסגרת החיתוך, גלגלת מקרבת ומרחיקה
  סביב נקודת הסמן, לחיצה כפולה מתקרבת ומתרחקת. במסך מגע: שתי אצבעות לזום וסיבוב.
- **סליידרים לכל דבר** — זום, סיבוב חופשי, מיקום אופקי ואנכי, בהירות, ניגודיות, רוויה,
  שחור־לבן, ספיה, טשטוש, רוחב הפלט ואיכות הדחיסה.
- **יחסי חיתוך** — יחסים מוכנים (1:1, 4:5, 16:9, 3:1 ועוד), יחס מותאם אישית,
  ויעדים מוכנים באתר שמגדירים גם את היחס וגם את רוחב הפלט (באנר, שיתוף ברשתות, אווטאר…).
- **שני מצבי התאמה** — *מלא מסגרת* (החיתוך תמיד מלא, בלי שוליים) או *התאמה מלאה*
  (כל התמונה נכנסת, עם רקע בצבע לבחירתכם או רקע שקוף).
- **פלט מדויק** — JPEG / WebP / PNG, רוחב בפיקסלים, בקרת איכות והצגת גודל הקובץ המשוער
  לפני השמירה.
- **עבודה בכמות** — "החל את ההגדרות על כל התמונות" ו"שמור את כל התמונות לאתר".
- **ספריית תמונות** — כל מה שנשמר מוצג למטה, עם העתקת קישור ומחיקה.

## נגישות

- כל פעולה שאפשר לעשות בעכבר אפשר לעשות גם בסליידר או במקלדת.
- מיקוד מקלדת על אזור החיתוך: חצים להזזה (עם `Shift` צעדים גדולים), `+`/`−` לזום,
  `[` ו-`]` לסיבוב (עם `Shift` — 15°), `0` לאיפוס.
- כל השדות מתויגים, הודעות מצב נקראות על ידי קורא מסך (`aria-live`),
  יש קישור דילוג לאזור החיתוך, סימון מיקוד ברור, ומצב בהיר/כהה נשמר בדפדפן.
- נשמר כיבוד ל-`prefers-reduced-motion` ול-`prefers-color-scheme`.

## הגדרות שרת

| משתנה סביבה | ברירת מחדל | תפקיד |
| --- | --- | --- |
| `PORT` | `3000` | הפורט להאזנה |
| `HOST` | `0.0.0.0` | הכתובת להאזנה |
| `UPLOAD_DIR` | `./uploads` | תיקיית שמירת התמונות |
| `PUBLIC_DIR` | `./public` | תיקיית קבצי הממשק |
| `MAX_UPLOAD_BYTES` | `26214400` (25MB) | מגבלת גודל לתמונה |
| `ADMIN_TOKEN` | ריק | אם מוגדר — נדרש מפתח גישה לכל קריאות ה-API |

דוגמה להפעלה מוגנת:

```bash
ADMIN_TOKEN="my-internal-secret" PORT=4000 npm start
```

הממשק יבקש את המפתח בפעם הראשונה וישמור אותו לחלון הדפדפן הנוכחי (`sessionStorage`).

## API

| שיטה | נתיב | תיאור |
| --- | --- | --- |
| `GET` | `/api/config` | מגבלת גודל והאם נדרש מפתח גישה |
| `GET` | `/api/images` | רשימת התמונות השמורות |
| `POST` | `/api/images` | שמירת תמונה: `{ fileName, dataUrl, metadata }` |
| `DELETE` | `/api/images/:name` | מחיקת תמונה |
| `GET` | `/uploads/:name` | הגשת התמונה עצמה |

התמונה נשלחת כ-`data:` URL שנוצר ב-canvas, כך שאין צורך בטיפול ב-multipart.
לכל תמונה נשמר קובץ `‎<name>.meta.json` עם פרטי החיתוך (יחס, זום, סיבוב, מיקום, פורמט)
לצורכי תיעוד — הקובץ אינו מוגש ואינו מופיע ברשימה.

## שילוב באתר קיים

`public/js/cropper.js` הוא מודול ES עצמאי שאינו תלוי בשאר הממשק:

```js
import { ImageCropper } from './js/cropper.js';

const cropper = new ImageCropper(document.querySelector('#stage'), { aspect: 16 / 9 });
await cropper.setImage(fileFromInput);

cropper.setZoom(1.8);
cropper.setRotation(-4);
cropper.setPanRatio({ x: 0.25 });

const { blob, width, height } = await cropper.toBlob({
  width: 1600,
  format: 'image/webp',
  quality: 0.9,
});
```

מתודות עיקריות: `setImage`, `setAspect`, `setZoom`, `zoomBy`, `setRotation`, `rotateBy`,
`toggleFlip`, `setPanRatio`, `panByPixels`, `setAdjustment`, `setFitMode`, `setBackground`,
`fillFrame`, `fitWholeImage`, `reset`, `getSnapshot`, `applySnapshot`, `getCropRect`,
`renderToCanvas`, `toBlob`. הארוע `change` נשלח בכל שינוי מצב.

`getCropRect()` מחזיר את אזור החיתוך כיחסים (0..1) מהתמונה המקורית, כך שאפשר לשמור את
ההגדרה במקום התמונה ולחתוך מחדש בצד השרת בעתיד.

## הערות מימוש

- מסגרת החיתוך קבועה במרכז והתמונה זזה מתחתיה. זו הסיבה שבמצב "מלא מסגרת" אף פעם
  לא נוצרים שוליים ריקים: הקלמפ של המיקום מחושב במערכת הצירים של התמונה המסובבת,
  ולכן הוא נכון גם בסיבוב חופשי.
- התצוגה החיה משתמשת ב-CSS filter והייצוא ב-`ctx.filter`; בדפדפנים שאינם תומכים
  ב-`ctx.filter` מופעל מעבר פיקסלים זהה, כדי שהקובץ שנשמר ייראה בדיוק כמו התצוגה.
- טעינת קבצים נעשית דרך `createImageBitmap` עם `imageOrientation: 'from-image'`,
  כך שתמונות מהטלפון נטענות בכיוון הנכון.
- המיקום נשמר כיחס מגודל המסגרת, ולכן שינוי גודל החלון לא מזיז את החיתוך.
